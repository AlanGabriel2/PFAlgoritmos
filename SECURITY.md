# Política de Seguridad

## Versiones soportadas

Este es un proyecto académico/de juego. Se da soporte de seguridad únicamente a la
última versión disponible en la rama `main`.

| Versión        | Soportada |
| -------------- | --------- |
| `main` (última)| ✅        |
| Anteriores     | ❌        |

## Reportar una vulnerabilidad

Si encuentras un problema de seguridad (por ejemplo, en el manejo de archivos de
guardado o de niveles JSON):

1. **No** abras un *issue* público.
2. Escribe de forma privada a **alansitoarteaga@gmail.com** con:
   - Una descripción del problema.
   - Pasos para reproducirlo.
   - El impacto potencial.
3. Recibirás una respuesta lo antes posible. Una vez confirmado y corregido el
   problema, se publicará la solución en `main`.

Gracias por ayudar a mantener el proyecto seguro.
